# 家庭财务全景

纯前端家庭财务仪表盘。首次访问不包含个人账本或资产数据；无需账号、后台或分析追踪。

## 使用

1. 在挖财导出账单明细 `.xlsx`，点击「导入挖财 Excel」或拖入页面。支持实际导出格式的前置信息行和五个表头：日期时间、类型、类别、金额、币种。新账本整体替换旧账本，不与旧数据叠加。开启余额自动调整后，会从保存的余额基准重新推算，重复导入不会重复累加。
2. 点击「填写 / 编辑」输入资产余额。金额单位为人民币元，股数为整数；负债填正数，零表示没有，空白表示未知。未知项会标记为部分净额，待归属股票不计入净资产。填写余额对应的北京时间；这是后续账本自动调整的起点。
3. 金山办公 `688111` 公开行情每 60 秒在页面可见时刷新。显示行情自身的时间，休市时可能是最近交易日。接口失败保留旧价格，也可输入手动价格。手动模式不被自动价格覆盖，点击「恢复采用自动行情」切换。
4. 定期导出 JSON 备份。恢复先校验版本和全部内容，再确认覆盖。备份版本为 `2`（兼容读取旧版 `1`），包含账本统计字段、资产快照、股价设置；价格和金额在备份中以整数分保存。

数据仅在当前网站来源的浏览器 `localStorage` 保存。不同设备、浏览器、网址之间不自动同步。清除浏览器数据会删除账本；隐私模式可能不保留数据。存储失败会提示并保留原状态。

## 账本自动调整

先填写准确的余额及其对应时间，再导入含“收付账户”和完整交易时间的挖财明细，点击「设置账本自动调整」确认账户分类并启用。类别建议只用于预选，保存后的明确分类才用于计算。新账户不会自动继承分类。

每次以不可变的余额基准为起点，只处理基准时间之后的记录；收入增加资产或减少负债，支出减少资产或增加负债。转账按两侧有符号金额处理，信用卡还款同时减少现金与负债，不影响净额。同一文件重复导入和修订后的账本均重新计算，不累加旧结果。余额调整记录按实际账户收支方向计入。

缺少时间、未知账户、起始余额未知、借贷、股票记录、转账金额不配平或推算余额为负时，整个余额推算暂停并显示基准余额，避免显示只更新了一半的总额。请核对提示，或手动保存新的真实余额基准后继续。基准日前的历史修正不会自动改写已确认余额。需导入覆盖基准日至今的完整账本；账本漏记、理财价格变化、待归属、股票数量变化仍需核对，结果是账本推算值而非银行实时余额。

首次使用旧版数据时重新导入一次挖财文件，补充本地账户和时间字段；原账本、快照与股价设置会保留。备份包含这些本地设置，不上传 GitHub。

## 统计口径

工资：收入类型中的「工资薪水、工资收入、加班收入」；奖金：收入类型中的「奖金」。允许类别使用 `/` 层级，以末级类别为准。公积金、福利补贴、兼职、股票、退款和余额调整不计入工资奖金；转账和借贷不计入。年度按账本日期，金额以分相加。保留负数修正，图形中的负值详见表格。

仅支持人民币，不自动猜测汇率。未知类型、币种、异常日期或金额会中止导入；旧数据保留。支持最多 100,000 笔和 30 MB 的文件，实际容量受浏览器存储限制。多个明细表要求先保留一个，避免重复计算。不自动修正历史记账差异。

## 隐私与依赖

- GitHub 仓库与 Pages 仅包含应用代码。页面不含真实资产、个人交易或家庭事件。
- Excel 在浏览器本地解析，仅保存日期、类型、类别、金额和币种；不保存原文件、备注、收付款人。账户名称和具体交易时间仅在浏览器内保存，用于转账配平和余额调整。账本与快照不会被上传。
- 唯一外部请求为固定代码 `688111` 的东方财富公开行情；不携带个人数据，禁用凭据和来源页面信息。公共接口无可用性承诺。
- SheetJS CE 0.20.3 随站点发布，运行时不从第三方加载脚本。来源与用法：[官方文档](https://docs.sheetjs.com/docs/getting-started/installation/standalone/)。许可见 `vendor/LICENSE.sheetjs`。
- 备份是包含个人信息的明文文件，请勿提交到仓库或公开分享。
- 同一 GitHub Pages 域名下其他站点共享浏览器来源。只在自己信任的 Pages 域名中使用；不要在同域部署不可信脚本。

## 本地预览与验证

在本目录启动静态服务：`python3 -m http.server 8765 --bind 127.0.0.1`，访问 `http://127.0.0.1:8765`。页面需要通过 HTTP(S) 打开；不建议使用文件预览。

运行计算与备份验证：`node --test tests/core.test.cjs`。测试仅包含虚构数据，不生成真实文件。

## GitHub Pages

公开仓库 `family-finance-dashboard`，主分支 `main`。在仓库 Settings → Pages 选择 GitHub Actions。工作流先运行验证，再只打包明确列出的公开页面文件，推送主分支后自动发布。无需服务器或秘密变量。

不要使用 `git add .` 上传财务目录；个人文件在 `.gitignore` 中被排除。发布工作流仅打包 `index.html / styles.css / core.js / app.js / favicon.svg` 和两份依赖文件，不发布测试、说明或其他目录。
